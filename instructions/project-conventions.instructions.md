# Project Conventions

- Discover the current repository topology, stack, versions, package manager, commands, architecture, and deployment target before choosing patterns.
- Existing repository instructions and working commands outrank Agent Forge defaults.
- Do not assume a monorepo, database, cloud provider, CI system, container runtime, or framework.
- Prefer the smallest cohesive change that fits existing boundaries.
- Document a durable architecture change when it alters public interfaces, data, trust boundaries, deployment, or compatibility.
- Mark uncertainty as assumption or needs validation.
