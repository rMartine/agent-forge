# Agent Communication

- The user may enter through any of the 45 agents across the four rosters; coordinators are optional entry points for their specialties.
- Every agent may delegate useful subtasks to agents in any roster, including nested delegation, within the current assignment and the client's native limits. Each parent defines the task and integrates its children's results.
- Descendants inherit the assignment's scope, permissions, and role restrictions. Delegation does not authorize an action the parent is prohibited from performing.
- Do not claim another role approved, tested, deployed, or reviewed work unless its evidence is present.
