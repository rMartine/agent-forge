# Elegir un método según la decisión

Los siguientes métodos son alternativas de análisis, no secciones obligatorias del entregable. Usa solo los pertinentes y deja visible lo desconocido.

| Decisión o pregunta | Método posible y evidencia necesaria |
|---|---|
| Dónde se concentra o se pierde el margen | Examinar competencia, sustitutos, clientes, proveedores y barreras de entrada mediante precios, contratos, capacidad y costos de cambio observados. |
| Qué cambio externo afecta la operación | Relacionar cambios políticos, económicos, sociales, tecnológicos, legales o ambientales con exposición, fecha y mecanismo concreto. Distinguir obligación vigente de propuesta. |
| Cómo responder con capacidades existentes | Contrastar fortalezas y debilidades internas con oportunidades y amenazas externas; cada combinación debe producir una acción sustentada. |
| Por qué el cliente elegiría una oferta | Comparar valor para el comprador, costo de servirlo, capacidades necesarias y respuesta de competidores. Una diferencia visible no demuestra demanda. |
| Dónde se crea valor o costo | Examinar actividades, costos y dependencias de la cadena de valor sin duplicar costos compartidos. |
| Si una capacidad da ventaja sostenible | Examinar valor, rareza, dificultad de imitación y capacidad organizacional de aprovecharla. Explicar la barrera de imitación y las condiciones que podrían erosionarla. |
| Si la organización puede ejecutar | Relacionar estrategia, estructura, sistemas, personas y habilidades con consecuencias observadas. No atribuir a la estructura un problema de habilidades sin demostrar el mecanismo. |
| Cómo distribuir recursos entre iniciativas | Comparar atractivo, capacidades, generación de caja, reinversión y restricciones. Las puntuaciones ordinales no equivalen a valor financiero; prueba si ponderaciones plausibles cambian la elección. |
| Cómo entrar a otro mercado | Comparar desarrollo propio, asociación, adquisición u otras formas pertinentes por acceso, inversión, control, reversibilidad e integración. Un mercado atractivo no demuestra viabilidad de entrada. |
| Cómo funciona un modelo de negocio | Relacionar clientes, oferta, canales, ingresos, actividades, recursos, socios y costos; un cambio en un componente puede alterar obligaciones y economía de los demás. |

Si se utiliza un modelo de plataforma, identifica participantes, aportaciones, contraprestaciones y quién paga. Examina adquisición inicial, liquidez, confianza, uso de varias plataformas y contribución económica. Los efectos de red necesitan evidencia de mayor valor para participantes conforme crece la participación.

Si se traduce una estrategia a indicadores, define resultado, medida, población, periodo, fuente, responsable y fundamento de la meta. Las relaciones entre indicadores son hipótesis de funcionamiento, no garantías. Evita una medida local que premie deteriorar el resultado de la operación completa.
