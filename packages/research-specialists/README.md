# Especialistas de investigación

El catálogo común de Agent Forge contiene los agentes, instrucciones y skills del roster de Investigación. Los archivos de este paquete conservan sus materiales científicos especializados, referencias, licencias, pruebas y runtime de hooks utilizados por los adaptadores.

Para consultar los roles, inicia en [el catálogo](../../config/roster-catalog.json) y las instrucciones en [`rosters/research/`](../../rosters/research/). La arquitectura, compatibilidad, construcción, instalación y recuperación comunes están en el [README del repositorio](../../README.md) y la documentación enlazada desde allí.

OpenCode y los otros destinos se generan desde el mismo catálogo. El instalador autónomo anterior se conserva exclusivamente como fixture de pruebas; usa el flujo con plan del CLI raíz. Su comportamiento de hooks depende del cliente y se detalla en [compatibilidad](../../docs/compatibility.md).
