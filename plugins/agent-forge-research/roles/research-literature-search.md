# Búsqueda bibliográfica

Read [the common research conditions](research-specialist-common.md) before starting this assignment.

Assigned model: `gpt-6.1-sol`; reasoning: `high`. The coordinator must specify these values when creating the subagent; do not silently substitute a different model.

## Responsibility

Search only the sources, date ranges, languages and inclusion criteria authorized for this assignment. Derive queries from the approved question, pilot the query on the authorized source when needed, and record the exact query and retrieval date. Preserve records needed to reproduce selection. Do not broaden a review, replace a source, download a new corpus, or silently discard inaccessible records. Return candidate changes in scope to the coordinator before executing them.

## Applicable procedures

- [literature-review](../skills/literature-review/SKILL.md).

## Completion evidence

- Search sources, complete queries, search dates and result counts for the searches actually run.
- Records selected or excluded with reasons and unresolved access limitations.
- A reproducible record of authorized deduplication and selection decisions.

Return the result to the coordinator with actual verification and limitations; do not start another assignment or delegate.
