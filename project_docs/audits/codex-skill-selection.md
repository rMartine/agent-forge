# Selección de skills para construir productos con Codex

Fecha de revisión: 2 de octubre de 2026. Destino: Codex Desktop y la extensión de Codex para VS Code.

## Resultado y límites de la comparación

Se seleccionaron seis skills externas para complementar procedimientos propios de Agent Forge. La selección se limita a las candidatas comparadas; no demuestra que sean las mejores de todo el catálogo. Todas se descubrieron mediante skills.sh y después se inspeccionaron en el repositorio del autor. No se usaron la popularidad ni las insignias del catálogo como prueba de seguridad o corrección.

El catálogo reproducible está en [config/external-skills.json](../../config/external-skills.json). Registra la página de skills.sh, el repositorio, la revisión completa, la licencia, los archivos, sus hashes SHA-256, la asignación de agentes, la condición de activación y las sustituciones exactas realizadas por Agent Forge. Los originales permanecen en la caché ignorada `.cache/external-skills/<id>/<revision>/`; no se modificaron esos bytes ni se ejecutó código descargado.

Las seis selecciones son referencias subordinadas al encargo de construir un producto. No activan al conjunto de agentes para consultas generales, investigación independiente o por detectar palabras como PostgreSQL o LangChain. Tampoco deciden la tecnología del producto: se consultan cuando la tarea y la tecnología ya justifican su uso. El agente principal conserva la coordinación, la integración y la responsabilidad del resultado.

### Candidatas evaluadas y no seleccionadas

Esta lista contiene las decisiones de descarte que sustentan la selección; no representa una búsqueda exhaustiva del directorio.

- [webapp-testing](https://www.skills.sh/anthropics/skills/webapp-testing) pide ejecutar scripts y prohíbe leerlos antes de probarlos. Ese procedimiento contradice la inspección requerida para esta integración. Se seleccionó Playwright del autor de la herramienta y no se descargaron ni ejecutaron los ayudantes de la candidata descartada.
- [web-design-guidelines](https://www.skills.sh/vercel-labs/agent-skills/web-design-guidelines) descarga instrucciones desde `main` en cada revisión. El árbol inspeccionado de `vercel-labs/agent-skills`, revisión `063bee94c3f4df8453406c830b0a7df0f2860278`, no aportó un archivo de licencia y el `SKILL.md` no declara licencia. No se redistribuye con una licencia supuesta ni se incorpora una dependencia mutable como instrucciones. La guía interna conserva la revisión de accesibilidad y experiencia de uso.
- [building-native-ui](https://www.skills.sh/expo/skills/building-native-ui) remite a un nombre que cambió en la fuente actual. Se comprobó también [expo-native-ui](https://www.skills.sh/expo/skills/expo-native-ui). La revisión `13ad8e05874195633b5c185f6947bb6400e228fc` exige consultar `expo-ui`, `expo-router` y `expo-animation`, y prescribe Expo Go antes de una compilación propia. No se integra un subconjunto con dependencias de instrucciones incompletas ni se impone esa secuencia a todos los productos móviles. Se conserva la guía propia para determinar framework, permisos, almacenamiento, estados sin conexión y comprobaciones de dispositivos.
- [supabase](https://www.skills.sh/supabase/agent-skills/supabase) abarca autenticación, almacenamiento, funciones y otros productos de ese servicio. Para el agente de base de datos se seleccionó la guía acotada de PostgreSQL: no se convierte Supabase en requisito general del producto.
- [architecture-decision](https://www.skills.sh/jwynia/agent-skills/architecture-decision) y [architecture-decision-records](https://www.skills.sh/wshobson/agents/architecture-decision-records) cubren alternativas y documentación de decisiones. La guía propia `record-architecture-decision` ya especifica contexto, restricciones, consecuencias, migración y evidencia. No se demostró una necesidad adicional que justificara incorporar otro procedimiento de coordinación.
- [technical-writing de Riekelt](https://www.skills.sh/riekelt/technical-writer/technical-writing) propone activar sus reglas para cualquier prosa técnica y añadir invocaciones a las instrucciones persistentes del repositorio. [technical-writing de Petalas](https://www.skills.sh/petalas/skills/technical-writing) añade una dependencia de otra skill de estilo. Las reglas de evidencia y lenguaje de Agent Forge y Roberto ya cubren este encargo; no se seleccionan esos procesos adicionales.
- [docker de anmolnagpal](https://www.skills.sh/anmolnagpal/devops-skills/docker) repite la instrucción de ejecutar scripts antes de leerlos. [devops-engineer de megastep](https://www.skills.sh/megastep/codex-skills/devops-engineer) introduce otra definición de rol y sus propias reglas de delegación. Se conservan los procedimientos propios de operaciones y los límites de despliegue autorizado.
- [electron de mxyhi](https://www.skills.sh/mxyhi/ok-skills/electron) se centra en automatizar aplicaciones existentes mediante depuración remota; no cubre la entrega de una aplicación de escritorio. [electron-base](https://www.skills.sh/jezweb/claude-skills/electron-base) fija una combinación de Electron 33, Vite, React y TypeScript. No se impone esa combinación al agente que también debe admitir Tauri, WPF, WinUI y otros frameworks determinados por el producto.
- [hugging-face-jobs](https://www.skills.sh/huggingface/skills/hugging-face-jobs) se orienta a infraestructura administrada y ejecución de trabajos externos. No se requiere ese servicio para todos los productos de aprendizaje automático. La guía propia conserva procedencia de datos, separación de conjuntos, reproducibilidad y evaluación.
- La búsqueda de gemelos digitales encontró [digital-twin-discharge-drafter](https://www.skills.sh/aipoch/medical-research-skills/digital-twin-discharge-drafter), orientada a documentos clínicos, y [i4h-catheter-navigation](https://www.skills.sh/nvidia/skills/i4h-catheter-navigation), específica de un flujo de navegación de catéteres. Ninguna corresponde a la responsabilidad general de implementar telemetría, sincronización, simulación y reproducción de eventos del producto. Se conserva la guía propia.

No se verificó licencia ni ejecución de todas las candidatas descartadas: el motivo de descarte indicado fue suficiente para no redistribuirlas. No se presenta la ausencia de selección como un defecto de toda la herramienta o del autor.

## Adaptaciones reproducibles

El catálogo registra 67 sustituciones exactas. Cada una especifica el archivo, texto original, reemplazo y motivo. El generador debe rechazar una sustitución si el texto no aparece exactamente una vez; no debe intentar adivinar una nueva versión del autor. Cambiar la revisión o los bytes exige volver a revisar el contenido y sus hashes.

Los cambios principales son los siguientes:

- Frontend: elimina la historia ficticia y la confirmación obligatoria de elecciones de diseño rutinarias.
- Playwright: elimina permisos específicos de otra plataforma, concesión de permisos de dispositivos, lectura del portapapeles personal, instalación global, eliminación de perfiles y cierre de navegadores ajenos. Conserva los comandos de pruebas y el uso de una sesión de trabajo identificada. Impide adaptar los resultados esperados para aceptar una regresión y evita exigir decisiones humanas que el coordinador puede resolver con requisitos vigentes. Las publicaciones de evidencia quedan condicionadas a su autorización explícita. La disponibilidad se comprueba resolviendo el ejecutable real `playwright-cli` y ejecutando su `--help`; la versión del ejecutor de pruebas `playwright` se comprueba por separado y no acredita la presencia del primero.
- OWASP: corrige referencias ASVS con los títulos de los archivos incluidos y reconoce dos referencias de OpenCRE ausentes en la fuente, sin inventar correspondencias. Elimina el procedimiento de reemplazar los datos desde una descarga nueva durante la ejecución. La modificación del README de ASVS conserva CC-BY-SA-4.0 y la atribución.
- LangChain: elimina actualizaciones incondicionales de dependencias y aclara que los ejemplos no cambian modelos de Codex, cuentas ni servicios.
- .NET: elimina instalación global y aplicación automática de migraciones sobre datos preservados. En las listas de comprobación, Minimal APIs, MVC, páginas, preparación de datos y ejemplos, una clave foránea ya no obliga a crear todas las operaciones de entidades relacionadas. Reutiliza registros, operaciones autorizadas y datos aislados de prueba; no crea un endpoint solo para preparar una prueba.
- PostgreSQL: limita el trabajo de rendimiento a solicitudes explícitas. Califica la existencia de restricciones por tabla; aclara que una variable de conexión no autentica al usuario y usa contexto de identidad limitado a la transacción para evitar arrastrarlo entre solicitudes.

Los originales, sus licencias y las razones de modificación deben acompañar al contenido instalado. La licencia combinada de OWASP describe documentación con dos licencias; no debe etiquetarse todo el contenido como si fuera exclusivamente CC-BY-4.0.

## Comprobaciones realizadas y comprobaciones pendientes

Se ejecutó una comprobación local con Node sobre el catálogo y la caché. Los resultados observados fueron seis skills, 140 archivos, 407263 bytes originales y coincidencia de los 140 hashes SHA-256. Las 67 sustituciones tuvieron una sola coincidencia y se aplicaron secuencialmente en memoria. La inspección de enlaces Markdown locales no encontró referencias a archivos Markdown faltantes después de aplicar las sustituciones. La búsqueda del contenido adaptado no encontró comandos de instalación global, concesión de permisos del navegador, eliminación de perfiles ni cierre global de procesos de Playwright.

Se conservaron los archivos de referencia de cada selección y los recursos externos a la carpeta de la skill que su procedimiento utiliza: procedimiento de OWASP, plantilla de hallazgos y datos ASVS. Los archivos seleccionados son Markdown y textos de licencia; no incluyen scripts ejecutables de terceros. La inspección estática no acredita que los ejemplos de todas las tecnologías hayan sido ejecutados ni certifica exhaustivamente todos sus criterios técnicos.

Se ejecutó además el resolvedor real `packages/core/dist/externalSkills.js`, sin descargas, sobre las seis selecciones. Produjo 146 archivos en memoria, incluidos seis archivos `SOURCE.json`. La regresión comprobó que el contenido .NET resuelto ya no contiene las órdenes de crear todas las operaciones de entidades relacionadas en MVC, Minimal APIs, preparación de Entity Framework ni la tabla de errores; también comprobó los reemplazos que reutilizan operaciones existentes o datos de prueba. Para Playwright comprobó la resolución del ejecutable real, la validación mediante `--help` y la separación entre el ejecutor de pruebas y la herramienta de automatización. Ambas regresiones pasaron; no ejecutan una aplicación .NET ni una sesión de navegador.

La instalación de las skills, su descubrimiento, la activación real, el comportamiento de los hooks y las pruebas del producto en Desktop y VS Code corresponden a las comprobaciones integradas del rediseño. Este informe acredita la selección, procedencia, revisión de instrucciones y preparación reproducible; no presenta esas comprobaciones de cliente como realizadas.
