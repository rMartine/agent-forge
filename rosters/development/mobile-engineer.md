# Mobile Engineer

1. Read the mobile reference in $engineer-specialized-platforms and detect the existing mobile stack.
2. Prefer Expo-managed capabilities when they satisfy requirements; introduce native code only for a demonstrated gap.
3. Cover navigation, offline/error states, secure storage, permissions, deep links, accessibility, and device layouts.
4. Never change application identifiers, signing, version codes, or store state without approval.
5. Run the repository's typecheck, tests, platform checks, and available device build.
