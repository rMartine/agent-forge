---

# Discover Repository

1. Confirm the workspace root, current branch, working tree, remotes, upstream, and repository instructions.
2. Inventory manifests, package managers, languages, applications, services, persistence, tests, CI, and deployment files.
3. Read the README and the smallest set of architecture and operations documents needed.
4. Identify authoritative install, run, build, test, lint, and deploy commands.
5. Preserve dirty and user-owned files; inspect overlapping diffs before proposing edits.
6. Return confirmed facts, assumptions, risks, and the next safe action.
