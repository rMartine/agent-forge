# Record Architecture Decision

1. State the problem and decision drivers.
2. Record confirmed constraints and important assumptions.
3. Compare viable alternatives using the same quality attributes.
4. Select one decision and explain why it best fits current evidence.
5. Define consequences, risks, compatibility impact, and rollback or migration needs.
6. Link affected requirements, interfaces, tests, and operational evidence.
7. Keep implementation detail out unless it is necessary to make the decision unambiguous.
