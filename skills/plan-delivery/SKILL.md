# Plan Delivery

1. Start from accepted requirements and repository constraints.
2. Split work into coherent, independently verifiable units.
3. Order dependencies and identify parallel-safe work.
4. Assign an owner role, expected artifact, verification, and completion gate to every unit.
5. Include migrations, compatibility, documentation, security, and release work where relevant.
6. Expose blockers and approval points; never hide them inside implementation bullets.
7. Report status using evidence, not estimated percentages.
